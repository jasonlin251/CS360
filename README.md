
# CS 360 - Android Event Tracking App

## Project Overview

This project is an Android event-tracking application created for my CS 360 Mobile Architecture and Programming course at Southern New Hampshire University.

The application allows users to create an account, log in, and manage events through a mobile interface.

## Features

- User registration and login
- Create, view, edit, and delete events
- Local data storage using SQLite
- Multiple Android screens and navigation
- SMS permission handling and a manual test message

## Technologies Used

- Java
- Android Studio
- SQLite
- XML
- Gradle

## Project Structure

- `app/src/main/java/` - Java application logic
- `app/src/main/res/` - Layouts and interface resources
- `app/src/main/AndroidManifest.xml` - Android application configuration
- `app/build.gradle` - Application build configuration

## What I Learned

This project introduced me to Android application development, database storage, user interface design, and software testing.

It also helped me understand how an application connects different components to provide functionality.

## Known Limitations

This is an academic project, not a production-ready application.

- Password storage needs improved security.
- Automatic scheduled SMS reminders are not implemented.
- Additional testing and security improvements are needed before real-world use.

## Career Relevance

This project demonstrates exposure to application development, database management, testing, and software troubleshooting.
