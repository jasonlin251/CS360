# CS 360 Mobile App Portfolio Reflection

For Project Three, I developed an Event Tracking App designed to help users create, view, and manage events. The main goal of the app was to give users a simple way to keep track of important events in one place. The app also included account login functionality and SMS permission features so users could receive notifications when needed.

The app required several screens to support the user’s needs. These included a login screen, an event list screen, an add event screen, and an SMS permission screen. I designed the interface to be simple and easy to understand so users could quickly find the features they needed. Buttons and input fields were placed in clear locations, and the navigation between screens was kept straightforward. I believe the design was successful because users could complete the main tasks without having to go through unnecessary steps.

When coding the app, I worked on one feature at a time instead of trying to build everything at once. I first created the basic screens and navigation and then added the functionality behind them. I tested each feature as I worked so I could identify problems early. This strategy helped make the development process more organized and is something I can continue using in future software projects.

I tested the application using the Android Emulator in Android Studio. I tested features such as logging in, adding events, moving between screens, and requesting SMS permissions. Testing was important because it showed whether the application worked the way I expected and helped me find errors before completing the project. It also showed me that an application can look correct but still have problems with its functionality.

One challenge during the development process was getting the different screens and features to work together correctly. I had to make adjustments to the code and test different solutions when something did not work as expected. This required me to troubleshoot problems and find ways to connect the user interface with the application logic.

I was particularly successful with the event management portion of the application. Creating the ability for users to add and view events demonstrated my understanding of Android development, user interface design, navigation, and application logic. Completing this project gave me more confidence in developing a mobile application from the initial design stage through testing and final implementation.
